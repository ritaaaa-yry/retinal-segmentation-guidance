# Citation and License Notes

This repository is a resource index for datasets and machine-learning algorithms used in retinal vessel analysis.

## Important Boundary

This repository should not redistribute third-party datasets, pretrained weights, or copied source code unless the original license explicitly permits redistribution.

## Recommended Use

1. Keep links to the original dataset and model repositories.
2. Record the exact paper or release used in experiments.
3. Add local result files only when they are generated by our workflow or are safe to publish.
4. Cite each original dataset and method according to the original authors' instructions.

## Items That Need Manual Review Before Public Release

- Dataset license and access terms.
- Whether downloaded dataset files can be re-uploaded.
- Whether pretrained model weights can be redistributed.
- Whether paper figures or tables can be copied.
- Whether any patient or sensitive metadata appears in local outputs.
