    Methodology

    What the score means—and what it does not mean

    Equal dataset weighting

    Metrics are averaged within each dataset first. The six datasets then receive equal weight, so a dataset with more images does not dominate the recommendation.

    No model-relative min–max scaling

    Fβ, TVS, clDice, and SF1 retain their original 0–1 meaning. Adding or removing a model therefore does not rescale every other model's score.

    No double counting

    F1, IoU, and MCC are related pixel metrics. Fβ drives the pixel score; IoU and MCC are shown only as consistency checks.

    Error profiles are diagnostic

    Boundary shift, width errors, missed vessels, and extra vessels explain failure mechanisms. Conditional error shares are not treated as absolute FN/FP burden and are not added to the score.

    Deployment is not ranked yet

    The current CSV bundle does not provide complete identical-hardware latency, FPS, and VRAM measurements. A deployment winner would therefore be unsupported.

    Target validation overrides the page

    This is benchmark-relative evidence from six datasets. Labelled validation on the user's actual target domain should take precedence over the displayed ranking.
