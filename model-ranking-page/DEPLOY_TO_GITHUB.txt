把这个完整文件夹上传到 GitHub 的方法
====================================

你要替换的目标目录：
retinal-segmentation-guidance/model-ranking-page/

本文件夹已经是完整网页，不是只包含数据或修改计划。

方法一：直接在 GitHub 网页上上传（最简单）
-------------------------------------------

1. 先解压我给你的 ZIP。

2. 打开仓库：
   https://github.com/ritaaaa-yry/retinal-segmentation-guidance

3. 进入当前的 model-ranking-page 文件夹。

4. 建议先备份旧页面：
   - 点击右上角 Add file；
   - 或者先在本地保留旧文件。

5. 删除 model-ranking-page 中原来的旧文件。
   需要替换的包括：
   - index.html
   - styles.css
   - src 文件夹
   - data 文件夹
   - tests 文件夹
   - README.md

6. 在 model-ranking-page 页面点击：
   Add file -> Upload files

7. 将解压后的 model-ranking-page-complete 文件夹“里面的全部内容”拖进去。
   注意：
   不要把外层 model-ranking-page-complete 再套一层上传。
   正确结构应当是：

   retinal-segmentation-guidance/
   └── model-ranking-page/
       ├── index.html
       ├── styles.css
       ├── README.md
       ├── .nojekyll
       ├── src/
       ├── data/
       ├── scripts/
       └── tests/

   错误结构是：

   retinal-segmentation-guidance/
   └── model-ranking-page/
       └── model-ranking-page-complete/
           ├── index.html
           └── ...

8. Commit message 填：
   Replace ranking page with bundled evidence implementation

9. 点击 Commit changes。

10. 等待 GitHub Pages 更新，通常需要 1–5 分钟。


方法二：使用 Git 命令上传（更稳妥）
-----------------------------------

1. 在电脑上打开终端，克隆仓库：

   git clone https://github.com/ritaaaa-yry/retinal-segmentation-guidance.git
   cd retinal-segmentation-guidance

2. 删除原来的网页文件夹：

   rm -rf model-ranking-page

   Windows PowerShell 使用：

   Remove-Item -Recurse -Force model-ranking-page

3. 将我提供的完整文件夹复制进仓库，并改名为：

   model-ranking-page

4. 检查目录：

   git status

5. 建议本地测试：

   cd model-ranking-page
   python scripts/build_data.py
   node tests/scoring.test.js
   python -m http.server 8000

6. 浏览器打开：

   http://localhost:8000

7. 确认网页没问题后，回到仓库根目录：

   cd ..

8. 提交：

   git add model-ranking-page
   git commit -m "Replace ranking page with bundled evidence implementation"
   git push origin main


GitHub Pages 设置
----------------

如果仓库已经开启 GitHub Pages，不需要重新设置，只需等待部署。

如果尚未开启：

1. 打开仓库 Settings。
2. 点击左侧 Pages。
3. Build and deployment 选择：Deploy from a branch。
4. Branch 选择 main。
5. Folder 选择 / (root)。
6. 点击 Save。

如果仓库首页不是直接展示 model-ranking-page，需要访问：

https://ritaaaa-yry.github.io/retinal-segmentation-guidance/model-ranking-page/


上传后必须检查的内容
--------------------

1. 页面打开后顶部应显示：
   - 5 models
   - 6 datasets
   - 1,220 model-image evaluations
   - 20 bundled source CSVs

2. 页面不应要求普通访客上传 CSV。

3. Task preset 可以切换：
   - Balanced multi-objective
   - Overall quality
   - Low FN / thin vessels
   - Low FP
   - Structural fidelity
   - Unknown-domain balanced

4. 页面应显示：
   - Final score
   - Pixel / Thin / Structure 子分数
   - Paired bootstrap top-1 frequency
   - Score 95% CI
   - 每个模型的 error composition

5. Audit 区域的 consistency checks 应全部为 PASS。

6. 页面应显示 threshold_source 方法警告。


以后替换新数据的方法
--------------------

1. 将新 CSV 替换到：
   model-ranking-page/data/source/

2. 保持 build_data.py 所需文件名不变。

3. 运行：

   cd model-ranking-page
   python scripts/build_data.py
   node tests/scoring.test.js

4. 再提交：

   git add data/source data/built
   git commit -m "Update model ranking evidence"
   git push origin main


重要说明
--------

1. data/source 中 20 个 CSV 都保留下来了。
2. 不是把 20 个 CSV 当成 20 个独立指标重复加权。
3. 三个 image-level CSV 用于实际评分。
4. error CSV 用于解释风险，不直接加进总分。
5. 其他汇总和重复 CSV 用于自动一致性检查。
6. 当前 deployment 数据不完整，因此网页没有虚构 deployment winner。
7. 当前 threshold_source 是 diagnostic test-set scan，网页会如实提示，不能写成 validation-only threshold。
